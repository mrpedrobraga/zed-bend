# Zed support for bend

This extension add suport for [Zed](https://zed.dev) for the [Bend 2](https://github.com/bendlang/bend) programming language.

## Features

- [x] Syntax highlighting for Bend 2 using [Soulthym's Tree-sitter grammar](https://github.com/Soulthym/tree-sitter-bend2)
- [ ] Language Server Integration (there's no LS yet AFAIK)
- [ ] Syntax highlighting for HV, maybe??? (Not sure if it's useful, and if it makes sense as part of the same extension).
